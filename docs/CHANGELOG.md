### 2단계 F109 — 예외 처리
- API 장애 대체 모델: 과부하·서버 오류(5xx)·429·시간 초과·연결 실패면 설정의 '장애 시 대체 모델'로 한 번 더 (다른 회사 모델 가능, 키 오류·연결 테스트는 대체 안 함, `llm.fallback` 기록)
- 무한 반복 차단: 미션의 AI 호출이 상한(기본 60회)에 닿으면 호출을 막고 승인함에 질문 + 푸시. 승인 = 60회 더, 거절 = 미션 일시정지. 미션 화면에 'AI 호출 n/상한'
- 체크포인트 재개: 진행 중인데 처리할 메시지·대기 승인 없이 10분 넘게 조용한 미션은 워커가 리더에게 이어서 진행을 보냄 (끊긴 Task 다시 지시, 같은 재개 반복 안 함). 미션 '재개' 버튼도 같은 방식
- 리더 처리 실패 질문을 거절하면 미션 일시정지 (자동 재개가 다시 시작하지 않게)
- 마이그레이션 0006: `organizations.fallback_model`, `missions.call_limit` / 테스트 9개 추가
